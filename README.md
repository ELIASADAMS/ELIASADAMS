## About

I'm **Ilya Minin (Eli)** — an artist and creative technologist working between **experimental music, vocal synthesis, generative systems, interactive media, animation, games and digital folklore**.

My projects often begin as software and become something more ambiguous: a voicebank, a song, a machine-like interface, an archive, a field recording, an audiovisual work, a game prototype, or a fictional system with its own rules.

A large part of my practice concerns **landscape, infrastructure, memory, Japanese folklore, ritual, forgotten voices and digital archaeology**. Code is not only a production tool here — it is part of the artistic material itself.

> **I make systems that can remember, mutate, sing, and document things.**

## Featured projects

### 🎼 響 Hiro — procedural UTAU `.ust` generator

[**`text-to-ust` →**](https://github.com/ELIASADAMS/text-to-ust)

A procedural Japanese lyric → UTAU UST generator designed as a **generative starting point and tuning assistant**, combining mora-aware phonemization, phrase analysis, procedural melody, scale/range constraints, motif memory, deterministic generation, timing and dynamics heuristics, pitch-accent-aware behaviour, bends and microtonal expression.

## Generative audio

I use code to build **musical environments rather than only individual tracks**. The Sonic Pi laboratory explores procedural ambient structures, evolving rhythm, broken groove, experimental percussion, ritual-inspired sonic palettes, environmental textures, feedback and memory systems, modular live-coding architectures and long-form generative transitions.

The emphasis is on **systems that behave**, rather than loops that merely repeat.

## Philosophy

I am interested in the point where a technical object starts behaving like a cultural object.

A voicebank can become a character.

A script can become a ritual.

A vending machine can become an archive.

A melody generator can become a collaborator.

A game prototype can become a record of a particular way of imagining a place.

A Blender file can become an archaeological record of a film, game or fictional world.

A rendering tool can become part of the aesthetic itself.

That is the territory I'm currently exploring.
